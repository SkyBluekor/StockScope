# StockScope v0.21.0.1 — Scanner Fast Start & Progress overlay

v0.21 Stock Scanner 위에 적용하는 성능/진행상태 개선 overlay입니다.

## 적용 순서
현재 v0.21까지 적용된 StockScope 프로젝트 루트에 이 ZIP의 내용을 그대로 덮어씁니다.

## 주요 변경
1. Scanner 자동 KRX 신규 요청 상한 기본 60회
2. 장기 과거 데이터 선다운로드 제거
3. 저장된 최근 데이터로 후보를 먼저 검색
4. 과거 근거가 없는 후보는 `과거 검증 전`으로 표시
5. 진행률을 실제 작업량에 맞춰 세분화
6. 현재 처리 종목 / 처리량 / 경과시간 / 마지막 진행 표시
7. 30초/90초 무진행 경고
8. 데이터 준비/빠른 검사/상위 후보 분석/전체 실행 시간 진단 추가

## 환경변수
```text
KRX_SCANNER_FAST_REQUEST_LIMIT=60
```

## 권장 확인
- 기존 Market Store가 충분한 상태에서 Scanner가 수백 회 다운로드를 다시 시작하지 않는지
- 진행률이 0→50→100으로 점프하지 않고 계속 갱신되는지
- 같은 날 다시 실행 시 Scanner 결과 캐시가 빠르게 재사용되는지
- 과거 데이터가 부족한 후보가 `현재 조건 기준 / 과거 검증 전`으로 표시되는지

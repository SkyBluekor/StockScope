# StockScope v0.20.2.3 — Result Consistency & Action Polish

## 목적
백테스트 결과에서 조건 개수와 실제 표시가 어긋나 보이던 문제를 정리하고, 초보 사용자가 지금 행동과 다음 행동을 바로 이해하도록 결과 카드를 마무리합니다.

## 변경
- 전체/충족/부족 조건 수를 한 줄에서 명확히 표시
- 가장 중요한 부족 조건 3개만 기본 노출, 나머지는 펼치기
- 충족 조건도 별도 펼치기로 확인 가능
- `현재 할 일 없음`을 `신규 진입하지 않기`로 변경
- 다음 행동을 `최신 확정 데이터가 나온 뒤 다시 분석`으로 명시
- 다음 분석 영역에서 부족 조건 카드를 중복 렌더링하지 않음
- 10개 전략의 초보자용 제목을 더 짧게 정리
- 상대강도/저점 구조 등 추상적인 조건 문구를 쉬운 표현으로 개선
- 추천 payload가 부족 조건을 4개로 잘라 버리지 않고 전체 조건을 유지

## 제외
전략 계산식, Risk Engine, 진입/청산 규칙, KRX API 호출 구조는 변경하지 않습니다.

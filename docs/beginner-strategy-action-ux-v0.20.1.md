# v0.20.1 Beginner Strategy & Action UX

## 문제

v0.20은 여러 전략을 자동 비교하지만 `모멘텀 지속`, `대기`, `거래량 20일 평균 1.2배` 같은 표현만으로는 주식 초보자가 의미와 행동을 바로 이해하기 어렵다.

`기다리기`, `확인하기`, `지켜보기`를 사용자 행동으로 쓰면 계산 가능한 판단을 다시 사용자에게 떠넘기게 된다.

## 결과 카드의 고정 순서

1. 현재 가장 적합한 쉬운 방법명
2. 괄호/보조 텍스트로 전문 전략명
3. 어떤 방법인지 쉬운 설명
4. 현재 판단
5. 왜 그렇게 판단했는지
6. 현재 사용자가 할 일
7. StockScope가 다음 분석에서 확인할 조건
8. 판단 변경 방식
9. 필요할 때만 전문 숫자와 근거 펼치기

## 행동 상태

- `ENTRY_CANDIDATE`: 진입 후보. 조건 계산은 완료됐고 실제 주문 여부는 사용자가 결정한다.
- `WAIT`: 현재 진입하지 않음. 사용자가 지표를 계산할 일은 없다.
- `NO_TRADE`: 현재 새 진입을 추천하지 않음.
- `NEEDS_VALIDATION`: 과거 표본이 부족하므로 진입하지 않고 추가 검증한다.

## A안 재평가

v0.20.1은 백그라운드 상시 감시를 하지 않는다.

다음 거래일 데이터가 확정된 뒤 사용자가 다시 분석하면 StockScope가 최신 확정 데이터로 다음을 자동 재계산한다.

- 10개 전략의 과거 적합도
- 현재 전략 조건
- 거래량/RSI/ATR/이동평균 등 기술 조건
- 손절 폭과 목표 여유 등 위험 구조
- 최종 추천 전략과 행동 상태

따라서 사용자에게 `거래량을 확인하세요`, `RSI를 지켜보세요`처럼 지표 확인을 숙제로 주지 않는다.

## 표현 원칙

전문용어는 없어지지 않지만 두 번째 정보로 내린다.

예:

- `모멘텀 지속` → `강한 상승 힘이 계속될 때 따라가기 (모멘텀 지속 전략)`
- `ATR 3.5% 이하` → `가격 움직임이 충분히 조용해지기` + 상세에 전문 기준
- `거래량 20일 평균 1.2배 이상` → `평소보다 거래가 20% 이상 활발해지기`

조건 하나가 맞았다고 바로 매수 상태로 바꾸지 않는다. 전체 전략 조건과 손절·목표 위험을 다시 평가한 뒤 `진입 후보`로 전환한다.

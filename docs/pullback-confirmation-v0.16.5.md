# Pullback Confirmation Engine v0.16.5

## 문제
기존 문구인 `눌림 지지 확인`, `20일선 지지를 확인`은 사용자가 다시 차트를 분석해야 한다는 문제가 있었습니다.

## 자동 판정 상태
StockScope가 다음 중 하나로 직접 분류합니다.
1. 눌림목 아님
2. 눌림 진행 중
3. 지지구간 접근
4. 지지 테스트 중
5. 반등 확인
6. 지지 실패

## 자동 점검
- 기존 상승 추세
- 최근 고점에서의 조정 폭
- 20일선/주요 지지구간 접근 여부
- 실제 지지 유지 여부
- 가격 반등 신호
- RSI 반등
- 반등 거래량

## EOD와 장중 시나리오
### KRX 확정 EOD
시가/고가/저가/종가/거래량이 모두 있으므로 지지 테스트와 반등 캔들을 확정 데이터로 판정할 수 있습니다.

### 사용자 현재 참고가격
현재가만 입력하면 오늘 저가·시가·거래량을 알 수 없어 일부 항목은 `미확정`으로 남깁니다.
오늘 저가와 누적 거래량을 추가 입력하면 장중 Preview 판정 범위가 넓어집니다.

## 사용자 경험
프로그램이 계산할 수 있는 항목에는 더 이상 `직접 확인하세요`를 기본 문구로 사용하지 않습니다.
대신:
- 앱 자동 확인 완료
- 앱 자동 확인 중
- 데이터 부족으로 미확정
중 하나를 명확히 표시합니다.

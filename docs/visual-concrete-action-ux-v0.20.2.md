# StockScope v0.20.2 — 가독성·다크모드·구체적 행동 안내 UX

## 목적

초보 사용자가 결과 화면을 오래 봐도 피로하지 않고, 전략 용어나 추상적인 문장을 해석하지 않아도 현재 상태와 다음 판단 조건을 이해할 수 있게 한다.

## 핵심 변경

- 상단 우측 다크/라이트 전환 버튼 추가
- 최초 실행은 OS의 현재 테마를 따르고, 사용자가 전환하면 `localStorage(stockscope-theme)`에 선택값 저장
- 전체 본문 기준을 17px로 올리고 주요 설명/버튼/입력의 최소 글자 크기를 함께 확대
- 폰트 확대에 맞춰 `min-height`, padding, grid `min-width: 0`, 자연스러운 한국어 줄바꿈을 적용
- 상세 표는 글씨를 다시 줄이지 않고 해당 표 영역만 가로 스크롤
- 멀티전략 결과에서 부족한 조건을 `현재 / 필요 / 상태`로 표시
- 조건 수치는 StrategyEngine이 사용한 동일 `StrategyInput`/technical snapshot에서만 계산하며, 계산할 수 없는 값은 억지로 만들지 않음
- `다음 분석에서 자동 재평가`라는 A안 유지. 백그라운드 상시 감시처럼 표현하지 않음
- 조건 하나 충족 = 즉시 매수로 연결하지 않고 전략/시장/Risk Engine을 다시 종합 판단한다고 명시

## 조건 표시 예시

```text
평소보다 거래가 20% 이상 활발해지기

현재  0.84배
필요  1.20배 이상
상태  ✕ 아직 부족
```

```text
최근 고점 가까이 올라오기

현재  종가 56,200원 · 20일 고점 57,800원 · 고점까지 2.8%
필요  20일 고점과 5% 이내
상태  ✓ 충족
```

## 줄바꿈/레이아웃 보호

- 버튼은 고정 `height`보다 `min-height` 우선
- 짧은 주요 액션 버튼은 한 줄 유지
- 설명 문장은 `word-break: keep-all` + `overflow-wrap: break-word`
- 1024px 이하에서 전략/조건 카드 1열 전환
- 전체 페이지 가로 스크롤 방지
- 긴 전문 표만 `.backtest-table-wrap` 내부에서 가로 스크롤 허용
- 760px 이하에서 테마 버튼은 아이콘형으로 축소

## 이번 버전에서 하지 않는 것

- 새로운 투자 전략
- Risk 정책 변경
- Scanner/Watchlist/알림
- KRX API 호출량 최적화

KRX API Budget/공용 Historical Store 최적화는 다음 v0.20.3 작업으로 분리한다.

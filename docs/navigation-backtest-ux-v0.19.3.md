# StockScope v0.19.3 — Navigation & Backtest UX Restructure

## 목표
빠른 조회와 백테스트를 한 페이지의 긴 스크롤로 이어 붙이지 않고 독립 기능으로 분리한다. 백테스트는 숫자표보다 목적·전략 개념·문제 해결 흐름을 먼저 이해할 수 있게 한다.

## 페이지 구조
- `/analysis`: 오늘의 시장 + 종목 빠른 조회 + 기존 분석 기능
- `/backtest`: 전략 백테스트 전용 화면
- 상단 네비게이션에서 두 기능을 직접 전환한다.
- 루트 `/`는 클라이언트에서 `/analysis`로 정규화한다.
- Cloudflare Pages 등 SPA 정적 호스팅의 직접 새로고침을 위해 `public/_redirects`에 `/* /index.html 200`을 둔다.

## 백테스트 내부 구조
- `설정`과 `결과`를 별도 탭으로 분리한다.
- 실행을 시작하면 결과 탭으로 전환하고 백테스트 화면 최상단으로 이동한다.
- 실행 완료 후에도 결과 최상단으로 복귀한다.
- 기존처럼 결과가 추가되며 브라우저가 페이지 맨 아래에 남는 동작을 방지한다.
- 결과 상세 근거 버튼처럼 사용자가 명시적으로 특정 상세를 요청한 경우에만 해당 상세 위치로 이동한다.

## 눌림목 초보자 설명
사용자 화면에서는 `Pullback` 대신 `눌림목`을 사용한다.

핵심 설명:
- 상승 중인 주식을 이미 많이 오른 가격에서 뒤늦게 따라 사는 위험을 줄이려는 방식이다.
- 상승 추세 중 일시 조정이 발생했을 때 추세와 지지가 유지되는지 확인한다.
- 가격이 다시 반등하고 RSI·거래량도 회복되는지를 StockScope가 자동 확인한다.
- 백테스트는 이 규칙을 과거에 반복 적용해 진입 시점·시장환경·손절 구조 중 어디에서 실패했는지 찾는다.

예시 가격 흐름:
`100,000 → 120,000 상승 → 113,000 조정 → 115,000 반등`

## 전략 확장 구조
백테스트는 하나의 큰 기능이고 눌림목은 첫 번째 지원 전략이다. 화면에 돌파/지지 반등/추세 회복 전략을 준비중 상태로 보여 향후 전략 추가 구조를 명확히 한다.

## 종목 선택
독립 `/backtest` 페이지 안에 종목 검색을 배치한다. 빠른 조회와 선택 종목 상태는 공유하지만 백테스트 설정·진행·결과는 백테스트 화면에서 독립적으로 관리한다.

## 변경하지 않은 것
- 백테스트 계산식
- Strategy Engine
- Entry Timing 계산
- Risk Engine
- Historical Store
- Job/진행률 API
- Problem Solver 백엔드 판정

## 검증 포인트
1. `/analysis`와 `/backtest` 전환 시 페이지 상단으로 이동한다.
2. 브라우저 뒤로가기/앞으로가기로 두 페이지 상태가 전환된다.
3. `/backtest`에서 종목을 직접 검색·선택할 수 있다.
4. 실행 시작/완료 후 결과 화면 최상단을 유지한다.
5. 설정과 결과가 동시에 길게 한 화면에 나오지 않는다.
6. 상세 표는 필요할 때만 펼친다.

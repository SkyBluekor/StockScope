## 1. 쉬운 결론

기존 R5는 수학적으로는 정리됐지만 실제 DGS10에 적용하려면 다음 population-level assumptions/constants를 감사 가능하게 승인해야 했다.

~~~text
A_R5_01 iid innovation representation
C_dep / rho
C_ls / zeta
L2
q / M_q
~~~

GA2와 GA2-BR1 결과 이 complete binding route는 확보되지 않았다.

따라서 MUR1은 기존 theorem을 다른 dependence theorem으로 바꿔 끼우는 대신, 실제 StockScope가 반드시 필요로 하는 출력과 불필요하게 강한 population inference를 분리했다.

최종 결정:


핵심 변화:

> population law가 일정하다는 확률적 주장을 하는 대신, 고정된 관측 경로에서 backward empirical distributions와 그 median/MAD가 얼마나 안정적이었는지를 직접 측정하고 인증한다.

이렇게 하면 실제 관측치로 감사 가능한 사실과 theorem-level population 가정을 섞지 않는다.

## 4. 후보 A — DIRECT_WEAK_DEPENDENCE_ROUTE

구상:

~~~text
현재 functional-dependence finite-memory proof
→
alpha/beta/phi mixing 또는 다른 weak-dependence concentration theorem
~~~

장점:

- population CDF inference의 큰 틀을 유지할 수 있다.
- empirical-process / concentration literature가 풍부하다.

문제:

- dependent-data concentration은 대체로 mixing rate, decoupling 또는 dependence coefficients에 대한 가정을 요구한다.
- 실제 DGS10에서 그 coefficient와 rate를 감사 가능하게 고정하는 문제는 그대로 남는다.
- rho를 없애도 mixing coefficient sequence라는 다른 unbound object가 들어올 가능성이 높다.

관련 문헌에서도 dependent time-series concentration은 summable uniform mixing 같은 dependence condition을 명시적으로 둔다.

판정:

~~~text
ASSUMPTION_REDUCTION = LOW
AUDITABILITY_GAIN = LOW
POPULATION_TARGET_PRESERVATION = HIGH
PRIMARY_SELECTION = NO
~~~

이 route는 현재 blocker의 이름만 바꿀 위험이 크다.

## 5. 후보 B — REGIME_OR_PIECEWISE_LOCALLY_STATIONARY_ROUTE

구상:

~~~text
global smooth local-law assumption
→
regime / piecewise locally stationary segments
~~~

장점:

- Treasury yield의 실제 regime variation과 잘 맞는다.
- global L2 assumption 부담을 크게 낮출 수 있다.
- sudden volatility changes를 명시적으로 허용할 수 있다.

문제:

- regime boundary 자체를 어떻게 prospectively 정의/검증할지 추가 governance가 필요하다.
- data-driven change-point selection 후 inference에는 post-selection 문제가 생긴다.
- segment 내부에서도 dependence/moment/local-law assumptions가 남는다.
- all-later comparison이 regime boundary를 넘을 때 의미를 새로 정의해야 한다.

Treasury literature는 실제 regime shifts를 강하게 지지하지만, 이것이 assumption-free inference를 제공하는 것은 아니다.

판정:

~~~text
ASSUMPTION_REDUCTION = MEDIUM
REGIME_REALISM = HIGH
AUDITABILITY = MEDIUM
PRIMARY_SELECTION = NO
SECONDARY_DIAGNOSTIC_VALUE = HIGH
~~~

향후 selected architecture 위에 descriptive regime annotation으로 붙이는 것은 유망하다.

## 6. 후보 C — BOUNDED_TRANSFORM_FINITE_SAMPLE_ROUTE

구상:

~~~text
raw feature
→ deterministic bounded transform / clipping / robust map
→ bounded-variable finite-sample method
~~~

장점:

- q / M_q tail burden을 제거하거나 크게 줄일 수 있다.
- extreme observations에 대한 numerical stability가 좋아진다.

문제:

- boundedness만으로 serial dependence가 사라지지 않는다.
- population CDF confidence band를 원하면 여전히 independence, exchangeability, martingale, mixing, decoupling 등 추가 assumptions가 필요하다.
- clipping을 도입하면 raw T/L/S target 의미가 바뀐다.

Conformal inference도 표준적으로 exchangeability를 필요로 하며 non-exchangeable extension은 별도 dependence/decoupling penalty를 요구한다.

판정:

~~~text
MOMENT_ASSUMPTION_REDUCTION = HIGH
DEPENDENCE_ASSUMPTION_REDUCTION = LOW
STANDALONE_SOLUTION = NO
PRIMARY_SELECTION = NO
COMPONENT_VALUE = MEDIUM
~~~

## 7. 후보 D — TARGET_REDUCED_OBSERVED_PATH_EMPIRICAL_STABILITY

구상:

latent population law F_h(u,x)를 추론하지 않는다.

각 chronology state t에서 prospectively fixed backward window W_t를 사용해:

~~~text
Fhat_h,t(x)
=
empirical CDF of observed h-horizon values in W_t
~~~

를 직접 계산한다.

Anchor s와 later v에 대해:

~~~text
T_emp,h(s,v)
=
sup_x |Fhat_h,v(x)-Fhat_h,s(x)|

L_emp,h(s,v)
=
|median_hat_h(v)-median_hat_h(s)| / MAD_hat_h(s)

S_emp,h(s,v)
=
|MAD_hat_h(v)-MAD_hat_h(s)| / MAD_hat_h(s)
~~~

를 계산한다.

anchor MAD가 0이면 기존처럼 fail-close한다.

이 값들은 probability statements가 아니라 fixed observed path의 deterministic summaries다.

장점:

- iid innovation representation 불필요.
- C_dep/rho 불필요.
- C_ls/zeta 불필요.
- global L2 불필요.
- q/M_q 불필요.
- alpha_stat 불필요.
- atomic/lattice와 ties를 자연스럽게 유지.
- all-later 및 latest-state를 정확히 계산 가능.
- prospective 18-anchor grid를 구조적으로 유지 가능.
- regime change를 assumption violation이 아니라 실제 empirical drift로 직접 관측.
- 모든 결과를 archived data에서 재현 가능.

대가:

- population-law confidence statement를 포기한다.
- '미래에도 안정적'이라는 확률적 보장을 하지 않는다.
- 결과 의미를 'historical observed-path empirical stability certificate'로 명확히 제한해야 한다.

이 제한은 단점이지만 현재 actual-process evidence보다 강한 주장을 하지 않는다는 점에서 governance상 장점이 더 크다.

판정:

~~~text
ASSUMPTION_REDUCTION = VERY_HIGH
AUDITABILITY = VERY_HIGH
REGIME_REALISM = VERY_HIGH
ALL_LATER_LATEST_SUPPORT = VERY_HIGH
HIDDEN_MODEL_RISK = VERY_LOW
POPULATION_INFERENCE_STRENGTH = LOW
PRIMARY_SELECTION = YES
~~~

## 8. 후보 E — EXPLICIT_PARAMETRIC_MODEL_ROUTE

구상:

~~~text
DGS10 generative model
=
regime-switching / time-varying AR / Markov / state-space
~~~

를 먼저 고정하고 해당 model에서 모든 constants를 유도한다.

장점:

- 잘 설계하면 current population-law target을 상당 부분 유지 가능.
- dependence / moment / local-law constants를 하나의 model에서 연결할 가능성이 있다.

문제:

- 실제 Reference Adequacy보다 generative model validation이 더 큰 프로젝트가 된다.
- model misspecification risk가 매우 크다.
- nominally nonparametric validation을 위해 강한 parametric model을 뒤에 숨기는 구조가 된다.
- regime model 선택, state 수, transition model, parameter uncertainty가 새 blocker가 된다.

판정:

~~~text
POPULATION_TARGET_PRESERVATION = HIGH
ASSUMPTION_BURDEN = VERY_HIGH
HIDDEN_MODEL_RISK = VERY_HIGH
IMPLEMENTATION_COMPLEXITY = VERY_HIGH
PRIMARY_SELECTION = NO
~~~

## 13. Window architecture

~~~text

=
{t-w+1,...,t}
~~~

- Reference Adequacy 결과를 보고 조정 금지

## 16. Regime handling

Regime/change-point detection은 primary gate에서 제외한다.

이유:

- regime detection 자체가 또 다른 statistical assumption/post-selection 문제를 만든다.
- selected empirical architecture는 regime change를 이미 drift spike로 직접 보여준다.

향후 optional observability로:

~~~text

~~~

를 추가할 수 있다.

중요:

감지된 regime를 이용해 불리한 구간을 retrospective exclusion하는 것은 금지한다.

## 21. 왜 이 방향이 StockScope 목적에 더 맞는가

Reference Adequacy의 실제 제품 질문은:

> 어느 정도의 historical reference 길이가 있어야 이후 관측 구간과 비교했을 때 분포/location/scale이 충분히 안정적으로 보이는가?

에 가깝다.

이 질문은 archived path의 empirical comparison으로 직접 계산할 수 있다.

현재 프로젝트가 실제로 증명할 수 없는 population process model을 추가하는 것보다:

~~~text
직접 측정 가능한 empirical stability
+
명확한 policy tolerance
+
all-later/latest verification
~~~

이 더 단순하고 감사 가능하다.

## 22. 문헌 기반 판단

Dependent empirical-process concentration은 stationarity/mixing/dependence 조건을 계속 필요로 한다. 따라서 DIRECT_WEAK_DEPENDENCE_ROUTE는 current blocker를 본질적으로 제거하지 못한다.

Non-exchangeable conformal methods도 표준 exchangeability를 벗어나는 대신 concentration/decoupling 또는 coverage penalty를 도입한다. 따라서 assumption-free population-law replacement로 볼 수 없다.

Treasury-yield literature는 10-year yield dynamics와 volatility에서 regime changes가 실재할 수 있음을 반복적으로 보고한다. 이는 global smooth-law assumption보다 regime-tolerant observed-path monitoring을 선호할 실증적 근거다.

# S23 — KRX 거래일 증거 공통 계약 (2026-10-14)

상태: **코드 계약 및 합성 회귀 구현 / 정식 2026년 전체 공인 거래달력 데이터 미확보**.
Master Architecture, Implementation Baseline, S20~S22 및 Q7/JEV/R5R 규칙이 우선한다.

## 목적과 달성 범위

- S21 공통 모듈을 확장하여 **공식 휴장 확인**, **공식 거래일 확인**, **실제 KRX 종목+지수 EOD 완전 저장**, **미확인**을 구분한다.
- 전체 연도 명세는 소스 원문을 확인한 코드 리뷰를 통해 반영하는 불변 연도별 증거로 제한한다. PARTIAL 원장에서 평일을 무조건 개장일로 간주하지 않는다.
- FULL 원장은 모든 평일을 공식 개장/휴장 중 하나로 분할하고, KRX 공식 증시일정 출처와 원문 SHA-256을 반드시 가진다. **SHA-256 입력값 자체는 원본의 진위를 자동 증명하지 않는다.** 출처 수집·확인 및 보관은 별도 검증이다.
- 현재 내장된 2026 PARTIAL 원장은 기존 S21에 확인된 **10/05, 10/09**만 보존한다. 그 밖의 2026년 특정 평일 휴장·공식 개장은 확정하지 않는다.
- 현재 공통 모듈 경로와 S16/S22 호출 계약을 보존한다. 날짜 충돌 및 결손은 평가를 보류하며 Risk, Frozen Capture, Tracking, Q7 승인, JEV 권한은 바꾸지 않는다.

## 상태와 해석

| 상태 | 근거 |
| --- | --- |
| CLOSED_VERIFIED | 소스가 있는 확정 휴장일 또는 주말 |
| OPEN_VERIFIED | 리뷰한 FULL 연도 원장에서 명시된 거래일 |
| STORED_COMPLETE | 해당 시장·일자에 종목+지수 실물 행과 완료 마커가 모두 존재 |
| OPEN_BUT_MISSING_EOD | 공식 개장일이지만 완전한 시장 자료가 없음 |
| UNKNOWN | 명확한 달력·EOD 근거 없음. 빈 응답도 휴장 증명이 아님 |
| PARTIAL_OR_UNVERIFIED_EXISTING | 종목 또는 지수 자료/상태가 불완전 |
| CLOSURE_DATA_CONFLICT | 공식 휴장 증거와 실제 저장 자료/상태 충돌 |

S20 PLAN의 기존 **MISSING** 표시는 위 **UNKNOWN**으로 변경해 무근거 개장 주장 가능성을 줄인다.
다만 S20 APPLY는 기존과 동일하게 사용자 명시 opt-in으로만 UNKNOWN 날짜의 KRX 종목+지수 쌍을 *탐색*할 수 있으며, 검증된 양쪽 데이터가 있을 때만 신규 완전 일자를 원자적으로 저장한다. 이는 공식 연간 달력 확정과 다르다.
S20 plan은 read-only이고, S16 및 S22는 같은 closure_evidence/unresolved_weekdays를 재사용한다.
기존 S22 성과 revision은 변경하지 않으며, S23 달력 버전 변경은 **새 계산에서 이전 캐시를 재검증**하기 위한 근거로 취급한다.

## 검증과 미완료

합성 회귀: 연간 전체 평일 분할 강제, 주말, 연말, 특별휴장, 부분 증거,
개장일 시세 누락, 종목+지수 완전성, 휴장 시세 충돌, 연도 경계, S20/16/22 호환.
실제 공급자 API 요청·운영 SQLite 변경·마이그레이션·예약 작업·배포는 이 PR에서 수행하지 않는다.

**후속 S23-B:** KRX 공식 "증시일정 > 휴장일"의 실제 2026년 전체 원본을 확보하여
날짜·발행시각·출처·원본 SHA-256을 검증하고, 공식 개장일 전수 대조 및 임시 휴장을 검증한
FULL 원장을 별도 코드 리뷰/PR로 추가한다. 동적 웹페이지의 빈 표를
공식 전체 휴장 목록으로 오인하지 않는다.

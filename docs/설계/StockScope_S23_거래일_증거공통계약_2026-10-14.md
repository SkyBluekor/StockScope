# S23 — KRX 거래일 증거 공통 계약 (2026-10-14)

상태: **코드 계약 및 합성 회귀 구현 / 정식 2026년 전체 공인 거래달력 데이터 미확보**.
Master Architecture, Implementation Baseline, S20~S22 및 Q7/JEV/R5R 규칙이 우선한다.

## 목적과 달성 범위

- S21 공통 모듈을 확장하여 **공식 휴장 확인**, **공식 거래일 확인**, **실제 KRX 종목+지수 EOD 완전 저장**, **미확인**을 구분한다.
- 전체 연도 명세는 소스 원문을 확인한 코드 리뷰를 통해 반영하는 불변 연도별 증거로 제한한다. PARTIAL 원장에서 평일을 무조건 개장일로 간주하지 않는다.
- FULL 원장은 모든 평일을 공식 개장/휴장 중 하나로 분할하고, KRX 공식 증시일정 출처와 원문 SHA-256을 반드시 가진다. **SHA-256 입력값 자체는 원본의 진위를 자동 증명하지 않는다.** 출처 수집·확인 및 보관은 별도 검증이다.
- S23-B에서 2026 PARTIAL 원장에 근거가 있는 **평일 휴장 17일**을 등록했다. KRX 공시부의 2026년 공식 공시 일정 PDF와 KRX 현물시장 휴장 규칙 및 6/03·7/17 거래소 공지로 교차 확인했다. **개장일 244일은 여전히 FULL로 검증되지 않았다**. 다른 평일을 자동 개장으로 단정하지 않는다.
- 현재 공통 모듈 경로와 S16/S22 호출 계약을 보존한다. 날짜 충돌 및 결손은 평가를 보류하며 Risk, Frozen Capture, Tracking, Q7 승인, JEV 권한은 바꾸지 않는다.

## 상태와 해석

| 상태 | 근거 |
| --- | --- |
| CLOSED_VERIFIED | 소스가 있는 확정 휴장일 또는 주말 |
| OPEN_VERIFIED | 리뷰한 FULL 연도 원장에서 명시된 거래일 |
| STORED_COMPLETE | 해당 시장·일자에 종목+지수 실물 행과 완료 마커가 모두 존재 |
| OPEN_BUT_MISSING_EOD | 공식 개장일이지만 완전한 시장 자료가 없음 |
| UNKNOWN | 명확한 달력·EOD 근거 없음. 빈 응답도 휴장 증명이 아님 |
| PARTIAL_OR_UNVERIFIED_EXISTING | 종목 또는 지수 자료/상태가 불완전 |
| CLOSURE_DATA_CONFLICT | 공식 휴장 증거와 실제 저장 자료/상태 충돌 |

S20 PLAN의 기존 **MISSING** 표시는 위 **UNKNOWN**으로 변경해 무근거 개장 주장 가능성을 줄인다.
다만 S20 APPLY는 기존과 동일하게 사용자 명시 opt-in으로만 UNKNOWN 날짜의 KRX 종목+지수 쌍을 *탐색*할 수 있으며, 검증된 양쪽 데이터가 있을 때만 신규 완전 일자를 원자적으로 저장한다. 이는 공식 연간 달력 확정과 다르다.
S20 plan은 read-only이고, S16 및 S22는 같은 closure_evidence/unresolved_weekdays를 재사용한다.
기존 S22 성과 revision은 변경하지 않으며, S23 달력 버전 변경은 **새 계산에서 이전 캐시를 재검증**하기 위한 근거로 취급한다.

## 검증과 미완료

합성 회귀: 연간 전체 평일 분할 강제, 주말, 연말, 특별휴장, 부분 증거,
개장일 시세 누락, 종목+지수 완전성, 휴장 시세 충돌, 연도 경계, S20/16/22 호환.
실제 공급자 API 요청·운영 SQLite 변경·마이그레이션·예약 작업·배포는 이 PR에서 수행하지 않는다.

## S23-B — 2026년 17개 휴장일에 대한 공식 출처 확인 (2026-10-14)

- 2026년 평일 휴장 17일에 대해 KRX 공시부 공식 휴장 구간 및 KRX 현물시장 규칙을 교차 확인했다.
- 6월 3일·7월 17일의 KRX KIND 공시는 **코넥스시장 한정**이다. 코스피·코스닥 휴장 직접 근거로 해당 URL을 쓰던 오류를 수정하여, 당시 KRX 전 증권시장 휴장 발표를 전달한 연합인포맥스 **2차 근거**로 표시했다. KRX 유가증권·코스닥 직접 공고 원본은 여전히 추가 확보가 필요하다.
- 2026년 5월 11일 시행된 공휴일 규정으로 제헌절이 공휴일이 되었으며, 공개된 KRX 휴장 공지와 일치한다.
- 기존 10월 5일·9일은 S21 출처 표기를 보존했다. 출처를 새로 붙였다는 이유로 Snapshot·시장 원본을 수정하지 않는다.
- 새로운 `S23_V3` 달력 버전은 S22의 재계산/캐시 근거 판정에서 구버전과 분리된다.
- 시세 없는 244개 평일을 자동으로 개장일이라고 추정하는 것은 금지한다. 가격 공백이나 과거 거래 정지 종목의 결손도 전시장 휴장 근거가 아니다.

## S23-C — 공식 휴장 원본 파일 감사 준비 (2026-10-14)

**구현 완료:** 다운로드한 원본 JSON/CSV에 대한 로컬 읽기 전용 증거 감사 계약.
**미완료:** 원본 KRX 사이트 다운로드 파일 확보, 원본 요청/시장/연도/조회 시각 입증,
공식 연간 개장일 전체 검증 및 \`FULL\` 운영 반영.

### 공식 원본 확보 경로

- KRX 공식 휴장일: https://open.krx.co.kr/contents/MKD/01/0110/01100305/MKD01100305.jsp
- 연도 \`2026\`, 시장 \`한국거래소\`(KRX) 선택 후 KRX 화면의 **조회/다운로드** 기능으로 공식 파일 확보.
- 동적 그리드가 빈 상태인 HTML, 캡처 화면, 비공식 캘린더나 임의 스프레드시트는 공인 원본 아님.
- 감사 도구가 직접 KRX 서버로 요청하거나 OTP/API를 호출하지 않음.
- 현재 도구는 **원본 JSON**(\`block1[].calnd_dd_dy\` 구조) 또는 **CSV**(\`일자\` 또는 \`Date\` 컬럼)만 지원. 과거 KRX 화면은 OTP 기반 Excel(xls) 다운로드 사례가 있으나 **현재 실제 포맷은 미확인**이다. XLS/XLSX/PDF/HTML은 파싱 없이 차단한다. KRX 실제 내보내기 형식과 다르면 새 계약 테스트/리뷰 후 별도 구현한다.

### 사용법 (PowerShell, 별도 로컬 파일)

\`\`\`powershell
cd C:\Projects\StockScope
.\.venv\Scripts\python.exe -B .\tools\data\krx_calendar_audit_s23.py --source-file "C:\Users\USER\Downloads\krx-2026-holidays.csv" --year 2026
\`\`\`

원본 SHA-256을 **별도 신뢰한 경로에서 이미 기록해 둔 경우에만** \`--expected-sha256 <64자 소문자 해시>\`를 추가한다.
이때 해시 일치는 파일 동일성만 검증하며 공식 다운로드 여부를 증명하지 않는다.
파일명·URL·파일 생성 시각은 출처 증명 자체가 아니다.

출력:
- \`MATCHES_REVIEWED_CLOSURES\`: 파일의 휴장일이 현재 17개 검토 휴장일과 일치한다는 **제한된 의미**만 가짐.
- \`REVIEW_REQUIRED\`: 추가 공식 휴장 또는 누락/필터된 원본 가능성. 기존 코드·DB로 자동 반영하지 않음.
- \`BLOCKED\`: 스키마, 원본 해시, 연도, 시장 구분, 중복 등 명확한 검증 오류.
- 모든 경우 \`download_origin_authenticated=false\`, \`full_calendar_eligible=false\`, \`runtime_calendar_updated=false\`.
- 정상 검사에는 **외부 요청 0, 런타임 DB 쓰기 0, 실제 Scanner/Capture/JEV 호출 0**.

### S23-C 후속 승인 조건

KRX 증시일정의 **진짜 2026년 전체 원본**(가능하면 원본 bytes, 쿼리 연도,
KRX 시장 구분, 공식 게시/다운로드 시점, 원본 해시)을 확보하고
검토된 휴장 17일 및 공지된 임시휴장 변경 이력을 독립적으로 대조해야 한다.
그 뒤에만 \`PARTIAL → FULL\`용 reviewed source commit 및 별도 승인 절차를 진행한다.
**검사 PASS는 244개 개장일을 공식 확인한 증거가 아니며, 2026년 10월 이후 미래 개장 보증도 아니다.**

## S23-C PR 리뷰 정정

- 6월 3일·7월 17일의 코넥스 전용 KIND 공시를 코스피·코스닥의 직접 근거로 잘못 사용하던 출처 범위를 정정했다. KRX가 전 증권시장 휴장을 발표했다고 전한 **2차 보도**와 공식 KONEX 공시를 명확히 구분한다.
- CSV 파일에서 열 개수가 맞지 않는 행을 Python DictReader가 묵인하던 문제를 `CSV_ROW_COLUMN_COUNT_INVALID`로 차단한다.
- 출처 버전을 S23_V3로 구분하며, Frozen 자료/과거 revision은 변경하지 않는다.
- KRX 공식 휴장일의 Excel 원본 다운로드는 최신 포맷 및 OTP 동작을 직접 확인하지 못했다. JSON/CSV 검사를 XLS 지원 완료로 표시하지 않는다.

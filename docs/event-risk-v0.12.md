# StockScope OpenDART Event Risk v0.12

## 목적

기술적 지표만으로 전략을 평가하지 않고, 최근 중요 공시가 기존 전략의 전제를 바꿀 수 있는지 자동 점검합니다.

## 데이터 우선순위

1. OpenDART 구조화 주요사항 API
2. OpenDART 공시 원문 `document.xml`
3. 공시 제목 기반 분류

## v0.12 구조화 지원

- 유상증자 결정
- 전환사채권 발행결정
- 신주인수권부사채권 발행결정
- 회사합병 결정

그 외 지원 이벤트는 중요도와 쉬운 설명을 제공하고, 가능한 경우 공시 원문에서 핵심 문장을 보조 추출합니다.

## 중요도

- HIGH: 신규 진입 Risk Gate 활성화
- MEDIUM: 주의 경고, 전략 자체는 자동 차단하지 않음
- LOW: 참고 정보

## 보유 중 대응

HIGH 공시가 있으면 기술적 구조가 유지되더라도 추가매수는 보류하고 공시 세부조건 확인을 우선합니다.
이는 실제 매도·매수 명령이 아니라 조건부 의사결정 보조입니다.

## 한계

공시 자동 요약은 OpenDART 원문을 대체하지 않습니다.
정정공시, 복잡한 첨부문서, 비정형 표는 자동 추출이 불완전할 수 있으므로 중요한 판단 전에는 DART 원문을 확인해야 합니다.

# Fundamental Engine v0.17

## 목표
재무제표 숫자를 길게 나열하지 않고, OpenDART 연간 사업보고서를 StockScope가 먼저 읽어 **기업의 재무 체력**을 결과 중심으로 설명합니다.

분석 화면의 기본 순서는 다음과 같습니다.

1. 재무 체력 종합 결론
2. 기업 유형 자동 분류
3. 수익성 / 성장성 / 재무 안정성 / 현금흐름 요약
4. 가격 배수(PER/PBR) 참고
5. 강점 / 주의점 / 다음 실적에서 다시 볼 조건
6. 사용자가 원할 때만 연도별 원시 수치 펼치기

## 데이터 원칙
- 재무: OpenDART `fnlttSinglAcntAll.json`의 연간 사업보고서(`11011`)
- 연결재무제표(CFS)를 우선하고, 없으면 별도재무제표(OFS)를 사용
- 최근 연간 자료끼리만 비교해 연간·분기 수치를 임의로 섞지 않음
- 가격: KRX 확정 EOD
- 사용자 현재 참고가격: 재무제표를 바꾸지 않고 PER/PBR Preview에만 사용

## 분석 항목
### 수익성
- 매출
- 영업이익
- 당기순이익
- 영업이익률
- 순이익률
- ROE
- ROA

### 성장성
- 매출 전년 대비 성장률
- 영업이익 전년 대비 성장률
- 순이익 전년 대비 성장률
- 매출은 증가하지만 이익이 감소하는 경우 별도 경고

### 재무 안정성
- 부채비율
- 유동비율
- 금융업은 일반 기업과 부채 구조가 달라 단순 기준 적용을 제한

### 현금흐름
- 영업활동현금흐름
- 투자활동현금흐름
- 재무활동현금흐름
- 유형/무형자산 취득액을 확인할 수 있으면 FCF 근사값 계산
- 순이익 흑자 + 영업현금흐름 적자는 `이익의 질` 경고

### 밸류에이션
- EPS: DART 보고값 우선, 없으면 현재 상장주식수로 보조 계산
- BPS: 자본총계 / 현재 상장주식수 보조 계산
- PER / PBR

PER/PBR은 업종과 성장률에 따라 적정 수준이 달라 **낮은 배수 = 저평가**, **높은 배수 = 고평가**로 단정하지 않습니다.

## 기업 유형
현재 엔진은 다음 유형을 자동 분류합니다.

- 고품질 성장형
- 수익성 개선형
- 저성장 안정형
- 외형 성장·이익 부진형
- 재무 주의형
- 적자·수익성 주의형
- 혼합형

## Analysis Hub 통합
`재무` Navigation이 추가됩니다.

종합 화면에도 `재무 체력` 신호가 들어갑니다. 예를 들어 가격·상대강도는 좋지만 재무 체력이 약하면:

> 가격 흐름은 강하지만 재무 체력이 이를 충분히 뒷받침하지 못합니다.

처럼 가격 분석과 기업 분석의 충돌을 프로그램이 먼저 설명합니다.

## 초보자 설명
다음 용어를 `?` 도움말과 전체 용어 사전에서 설명합니다.

- 매출 / 영업이익 / 순이익
- 영업이익률
- ROE / ROA
- 부채비율 / 유동비율
- 영업활동현금흐름 / FCF
- EPS / BPS
- PER / PBR
- 시가총액
- 재무 체력

## 제한
- OpenDART 계정명이 기업별로 다를 수 있어 표준 IFRS account_id와 한국어 계정명을 함께 매칭합니다.
- 자동 구조화가 불가능한 계정은 추정하지 않고 `데이터 부족`으로 둡니다.
- 재무 체력은 단기 주가 상승확률이 아닙니다.
- 실제 주문 기능은 제공하지 않습니다.

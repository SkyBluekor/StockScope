# StockScope StockCode Domain Rule v0.8.1

## 확정 규칙

- KRX 단축 종목코드는 **정수형이 아니라 문자열 식별자**로 취급한다.
- 길이는 6자이며 `0-9`, `A-Z`를 허용한다.
- `005930`, `0011A0` 모두 정상 코드다.
- 앞자리 0을 보존해야 하므로 `int(stock_code)` 변환을 금지한다.
- 프론트, KRX Provider, OpenDART 매핑에서 모두 대문자 문자열로 정규화한다.

## 검증식

`^[0-9A-Z]{6}$`

이 규칙은 실제 매매 기능과 무관한 조회/분석 식별자 규칙이다.

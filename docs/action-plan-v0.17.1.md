# Action Plan UX v0.17.1

## 목적
Analysis Hub가 많은 분석 결과를 보여주는 것에서 끝나지 않고,
사용자가 현재 상태에서 무엇을 해야 하고 무엇을 기다리는지 먼저 이해하도록 합니다.

## 첫 화면 순서
1. 현재 행동 단계
2. 지금 할 것
3. 지금 피할 것
4. 앱이 자동으로 보는 가격 기준
5. 판단이 바뀌는 시나리오
6. 현재 결정에 중요한 분석 Top 3
7. 나머지 분석 결과 / 근거는 기본 접힘
8. 상세 Navigation

## 전략 적합도와 행동 단계 분리
`전략 적합도 100/100`은 해당 전략의 형태와 조건이 많이 맞는다는 뜻입니다.
현재 진입 신호 또는 상승확률 100%라는 뜻이 아닙니다.

예:
- 20일선 반등 적합도 100점
- 반등 신호 대기
- 시장 상대강도 약세

이 경우 프로그램은 높은 전략 점수를 유지하면서도 현재 행동은 `대기`로 표시합니다.

## 가격 기준
가능한 값은 사용자가 직접 차트에서 찾게 하지 않고 앱이 보여줍니다.
- 주요 지지 가격
- 전략 무효화 가격

가격 기준이 실제로 계산되지 않은 경우 임의의 숫자를 만들지 않습니다.

## 정책
모든 결과는 분석·시뮬레이션용 의사결정 보조입니다.
StockScope는 실제 증권 주문을 생성하거나 실행하지 않습니다.

# Investor Style Engine + Style Playbook v0.18

## 목적
v0.18은 유명 투자자 이름을 붙인 점수표가 아니라, 사용자가 투자 철학의 차이를 이해하고 자신에게 맞는 기준으로 종목을 해석할 수 있게 하는 레이어입니다.

평가 대상:
- Buffett 스타일
- Graham 스타일
- Peter Lynch 스타일
- CAN SLIM 스타일

## 공통 원칙
- 스타일 점수는 조건 적합도이며 상승확률이 아닙니다.
- 실제 투자자의 개별 의사결정을 복제한다고 주장하지 않습니다.
- UNKNOWN 데이터는 0점 벌점으로 처리하지 않고 평가 커버리지에 따로 표시합니다.
- 장기 기업 적합성과 현재 단기 진입 상태를 분리합니다.
- 실제 주문 기능은 없습니다.

## Buffett
핵심: 좋은 사업 + 지속 가능한 이익/현금흐름 + 과도하지 않은 가격.

주요 자동 조건:
- ROE
- 영업이익률
- 최근 연간 흑자 지속
- 재무 안정성
- 영업현금흐름
- 영업현금/순이익 관계(이익의 질)
- FCF
- 장기 이익 성장
- PER 가격 부담

## Graham
핵심: 재무가 버틸 수 있는 기업을 충분히 보수적인 가격에 검토.

주요 자동 조건:
- 흑자 지속
- 재무 안정성
- 유동비율
- 부채비율
- PER
- PBR
- PER×PBR 보조 조건

PER/PBR 기준은 절대적인 내재가치 계산이 아니라 StockScope의 보수적 screening heuristic입니다.

## Peter Lynch
핵심: 성장 속도와 가격의 균형.

주요 자동 조건:
- 최근 이익 YoY
- 최근 연간 이익 성장
- 최근 매출 YoY
- PEG 참고값
- 재무 안정성
- 현금흐름
- PER 부담

최근 성장률로 고성장형/안정성장형/저성장형/성장 둔화형의 단순 성격 안내도 제공합니다.

## CAN SLIM
StockScope가 현재 확인 가능한 데이터로 다음을 모델링합니다.
- C: 최신 분기·반기 이익 성장
- A: 최근 연간 이익 성장
- N: OpenDART에서 확인 가능한 긍정 신규 재료
- S: 거래량 및 20일 고점 접근
- L: 시장·업종 상대강도
- I: 기관 후원 데이터 미수집 → UNKNOWN
- M: StockScope 시장 국면 proxy

I를 확보하지 못했다고 0점 처리하지 않습니다.

## Style Playbook
각 스타일 상세 화면은 다음을 제공합니다.
1. 핵심 철학
2. 투자 진행 순서
3. 잘 맞는 사용자
4. 덜 맞는 사용자
5. 현재 종목에서 강점/약점
6. 선택 스타일 기준 현재 적용 방향
7. 계속 확인할 것
8. 피할 해석
9. 스타일 판단 재평가 조건
10. 상세 조건(기본 접힘)

## 사용자 성향 안내
세 개의 간단한 선택 질문으로 어느 투자 철학과 가까운지 학습용으로 비교합니다.
이 결과는 금융상품 적합성 진단이나 수익 가능성 평가가 아닙니다.

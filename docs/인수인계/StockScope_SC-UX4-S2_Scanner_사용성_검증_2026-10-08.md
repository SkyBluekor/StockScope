# StockScope SC-UX4-S2 — Scanner 사용성 마무리 및 검증

작성일: 2026-10-08
기준: `main`의 `e889ca8`에서 파생한 `feature/sc-ux4-s2-scanner-usability`

## 목표와 실제 변경

주식 초보자가 종목을 5초 안에 비교하고 다음 행동을 이해할 수 있는 정보 구조를 목표로 한다. 5초는 아직 **실측되지 않은 UAT 목표**이며, CI 통과만으로 이를 달성했다고 판단하지 않는다.

| 영역 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 후보 5개 | 전략명/충족수/부족조건/AI 미제공/가격 상태가 행마다 중복 | 순위·종목명·시장·충족수·가장 중요한 조건/위험 근거 중심. 관심/보유 버튼은 유지 |
| 후보 확장 | 추가 10개를 접으면 선택 종목을 강제로 1번으로 변경 | 선택 종목 ID 유지. 추가 후보가 선택된 채 접으면 해당 행만 고정 표시 |
| 후보 비교 | 전체 15개 확장 시 목록 아래로 밀림 | 기본 5개 직후 순위 비교 진입점 배치 |
| 오른쪽 요약 | 위험·다음 확인을 나란한 박스에 중복, 별도 긴 주의사항 | 간결한 결론/조건 현황/대표 부족 조건/위험이 있을 때만 주의/다음 확인/가격/AI·과거 상태/뉴스 제목 최대 2건 |
| 오른쪽 하단 | 여러 문장과 관리 정보·링크가 좁은 공간에서 충돌 | 내 종목 상태 1행, '전문 분석 보기' 기본 행동 및 조건부 '내 종목 관리' 두 버튼 |

## 반드시 유지하는 것

- Scanner 종목 선정·순위 및 risk/strategy 판단과 가격 계산.
- 선택된 후보·확장 상태·세션 복원, 관련 Jev 결과의 캡처/종목 일치 검증.
- 관심/보유 등록, 전문 분석 이동, JEV-X2, 3년 근거 준비, KIS 수동 시세 확인, 뉴스 조회.
- Jev 실제 호출 비활성 `BASELINE_ONLY`과 기능 미제공 표시. 사용자가 켜는 설정을 임의로 활성화하지 않음.
- 다른 컴퓨터 Runtime 전송 보류.

## 검사

- Python 기존 SC-UX1/2/3/4 계약 및 신규 `backend/tests/test_sc_ux4_s2_scanner_usability_contract.py`.
- 프론트엔드 문구·조건값 JS 테스트, 전체 타입 검사/빌드.
- GitHub CI Python 3.11/3.14, Frontend Node 22, Windows Fresh Clone.
- 실제 현재 PC UAT: **1440×900, 1280×720, 768px, 390px**에서 5/15 후보, 확장 후 선택 유지, 스크롤, 상세 5개 탭, 두 가지 관리 행동, 긴 조건을 확인.
- 전체 페이지 캡처에서 sticky 상단 내비게이션이 겹쳐 보이는 것은 **실제 뷰포트에서 재현되기 전까지 확정된 레이아웃 버그로 취급하지 않음**.

## 완료 판정

코드 및 CI 검증과 실제 브라우저 시각적 검증을 반드시 분리해 보고한다. 변경 전후 스크린샷은 사용자의 현재 PC에서 확인해야 하며, 아직 생성되지 않았다면 완료로 간주하지 않는다.

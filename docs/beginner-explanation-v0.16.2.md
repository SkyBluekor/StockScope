
# Beginner Explanation Layer v0.16.2

## 목적
StockScope가 계산한 전문 지표를 사용자가 다시 검색하거나 공부해야 이해할 수 있다면 분석 서비스의 역할이 부족합니다.
v0.16.2는 전문 용어를 그대로 나열하지 않고 현재값에 맞춰 쉬운 말로 번역합니다.

## 현재값 동적 해석
예:
- RSI 68 → 상승 힘이 강하지만 과열 기준 70에 가까움
- RSI 75 → 과열 구간이지만 즉시 하락을 뜻하지는 않음
- 거래량 2.1배 → 최근 20일 평균보다 거래가 매우 많이 몰림
- 현재가가 지지선 +1.2% → 지지 유지 여부를 가까이서 확인할 수 있는 위치
- 현재가가 저항선 -1.0% → 기존 저항을 넘어선 상태로 돌파 유지 여부 확인

## 인라인 도움말
다음 용어 옆 `?`에서 즉시 확인할 수 있습니다.
- 이동평균선 / 20일선
- RSI
- ATR
- 거래량 비율
- 지지선 / 저항선
- 상대강도
- 전략 무효화
- 손절 참고구간
- 목표가
- R:R
- Risk Gate
- 전략 적합도

## 전체 용어 사전
돌파, 눌림목, 모멘텀, 추세, 과매수/과매도, 고점·저점 상승, EOD, 공시 영향 등 자주 쓰는 용어를 한 화면에서 다시 볼 수 있습니다.

## 설명 원칙
1. 전문 용어를 다른 전문 용어로 설명하지 않습니다.
2. 숫자 정의보다 사용자가 현재 상태를 이해하는 것을 우선합니다.
3. `RSI 70 = 매도`처럼 잘못 단정하기 쉬운 해석에는 주의 문구를 함께 제공합니다.
4. 전략 점수는 상승 확률이 아니라 조건 적합도라는 점을 반복해서 명시합니다.
5. 실제 매수·매도 주문을 실행하지 않습니다.

# StockScope v0.19.2 — Backtest Problem Solver

## 목적

v0.19.2는 백테스트 결과를 숫자로 보여주는 데서 끝내지 않고 다음 흐름으로 바꾼다.

`과거 데이터 → 문제 탐지 → 원인 후보 → 해결/검증 방법 → 다음 실행`

핵심 원칙은 사용자가 승률, Profit Factor, MDD, 진입 조건 표를 직접 해석해 전략 문제를 찾아야 하는 구조를 없애는 것이다.

## 사용자 화면 우선순위

1. 선택 종목/기간에서 현재 전략 근거가 충분한지
2. 성과 / 위험 / 결과 신뢰도
3. StockScope가 발견한 문제
4. 각 문제의 근거, 의미, 해결 방법
5. 앱이 바로 수행할 수 있는 다음 검증
6. 숫자·거래 상세는 근거 영역에서 펼쳐보기

한 종목의 결과를 눌림목 전략 전체의 성패로 확대해석하지 않는다.

## 보수적 해석 기준

### 표본 신뢰도

- 10건 미만: 매우 낮음. 전략 성패보다 표본 확대가 우선
- 10~29건: 낮음. 방향성 확인은 가능하지만 규칙 변경 근거로 부족
- 30~59건: 보통. 반복 패턴 비교 가능, 외부 재현 검증 필요
- 60건 이상: 높음. 해당 종목·기간 내부에서는 비교적 충분, 다른 기간/종목 검증 필요

이 숫자는 통계적 유의성을 보장하는 임계값이 아니라 StockScope가 과한 결론을 막기 위한 UX/판정 가드레일이다.

### 자동 문제 탐지

- 낮은 표본
- 음(-)의 거래당 평균과 Profit Factor 1 미만이 함께 나타나는 손익 부진
- 실제 거래의 60% 이상이 손절 계열 종료인 경우
- 3/7~7/7 연구에서 현재 실제 규칙보다 의미 있게 나은 진입 타이밍 후보가 있는 경우
- 시장 국면별 평균 손익 차이가 큰 경우

각 탐지는 즉시 전략 규칙을 변경하지 않는다. 표본이 부족하면 반드시 `추가 검증 후보`로만 표시한다.

## 자동 실행 가능한 해결책

낮은 표본이면 사용자가 날짜를 계산하지 않도록 `3년으로 다시 검증` 또는 `5년으로 다시 검증` 버튼을 제공한다.

- 약 1년 결과에서 표본 부족 → 3년 확대
- 이미 약 3년을 검증했는데도 표본 부족 → 5년 확대

현재 최대 5년 제한을 유지한다.

진입 타이밍과 시장환경 문제는 해당 근거 영역을 앱이 바로 열어 보여준다.

## 전략 개선 후보 가드레일

다음 조건을 동시에 만족할 때만 진입 타이밍을 `개선 후보`로 승격한다.

- 실제 규칙 거래 30건 이상
- 후보 진입 타이밍 연구 거래 20건 이상
- 후보 평균 수익이 양수
- Profit Factor가 없거나 1.2 이상
- 현재 실제 규칙보다 거래당 평균 결과가 최소 0.75%p 개선

후보가 생겨도 자동으로 실제 Strategy Engine 규칙을 바꾸지 않는다. 다른 기간·다른 종목에서 별도 재검증한다.

## v0.19.2에서 변경하지 않는 것

- 눌림목 신호 계산
- Risk Engine 계산
- Stop / Target 체결 규칙
- 다음 거래일 시가 진입
- 최대 보유기간 처리
- KRX Historical Store / Job / 진행률 구조
- OpenDART 제외 정책

따라서 v0.19.2는 백테스트 결과 자체를 바꾸는 버전이 아니라 결과를 문제 해결에 연결하는 해석·행동 레이어다.

## 다음 정확성 점검

성능/UX 작업 이후 별도로 실제 거래의 손절 가격이 과도하게 멀어지는 사례를 검증한다. 예를 들어 이전 삼성전자 결과의 `331,000원 진입 → 274,722원 청산`처럼 큰 손실이 정상적인 Risk Engine 무효화 가격 때문인지, 갭 처리인지, 연결 오류인지 거래 상세와 계산 경로를 추적한다.

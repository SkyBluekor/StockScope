# Investor Style Action Engine v0.18.1

## 핵심 원칙
앱이 계산할 수 있는 재무·가격·상대강도 조건을 사용자에게 다시 `확인하세요`라고 지시하지 않습니다.

표현 순서는 다음으로 고정합니다.
1. 현재 행동
2. 앱 자동판정
3. 왜 그런가
4. 다음 데이터에서 앱이 자동 재확인할 조건
5. 상세 원시 데이터

## 스타일별 자동판정
- Buffett: 기업 품질 / 재무안정성 / 현금창출력 / 가격 매력
- Graham: 가격 할인 / 재무안전성 / 흑자 지속성
- Peter Lynch: 성장성 / 성장 대비 가격 / 재무안정성 / 현금흐름
- CAN SLIM: 실적 성장 / 수요·거래량 / 시장 주도력 / 시장 환경 / 신규 성장재료

## 현재 행동과 스타일 적합도 분리
스타일 적합도가 높아도 Risk Gate가 활성화되거나 가격 반등이 미확정이면 현재 신규 진입 단계는 대기로 표시합니다.
반대로 반등 확인이 되더라도 스타일 적합도가 낮으면 해당 스타일의 우선 후보로 자동 승격하지 않습니다.

## 자동 재평가
새 OpenDART 실적, KRX EOD 가격·거래량·상대강도, 공시가 들어오면 조건을 다시 계산합니다.
UNKNOWN은 임의 추정하지 않습니다.

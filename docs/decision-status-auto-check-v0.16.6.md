# Decision Status & Auto Check UX v0.16.6

## 목적
v0.16.5의 `앱 자동 확인 대기` 같은 표현은 백엔드가 실제로 계산한 상태를 지나치게 압축했습니다.
v0.16.6은 사용자가 차트를 다시 읽지 않아도 **현재 단계, 확인된 조건, 부족한 조건, 다음 자동 확인 시점**을 알 수 있게 합니다.

## 상태 표현
눌림·지지 엔진은 다음 단계를 구분합니다.

- 눌림목 아님
- 눌림 진행 중
- 지지구간 접근
- 지지 테스트 중
- 반등 신호 대기
- 반등 확인
- 지지 실패

`반등 신호 대기`는 지지 유지까지는 확인됐지만 가격 반등/RSI/거래량 같은 회복 신호가 부족한 상태입니다.

## 자동 확인 진행도
분석 결과는 `auto_check` 공통 모델을 제공합니다.

- PASS 조건 수
- FAIL 조건 수
- WARN/UNKNOWN 조건 수
- 전체 조건 수
- 진행도 %
- 아직 확인 중인 조건과 현재 값
- 실패한 조건과 이유
- 선택적으로 추가 입력하면 정확도가 높아지는 장중 데이터
- 다음 자동 재판정 시점 설명

진행도는 **조건 확인 개수**이며 상승확률이나 전략 성공확률이 아닙니다.

## EOD와 장중 Preview
### KRX 확정 EOD
장 마감 후 확정된 일봉을 사용합니다. 다음 KRX 거래일 데이터가 들어오면 자동 재판정합니다.

### 장중 Preview
사용자의 현재 참고가격/오늘 저가/누적 거래량 등을 임시로 반영합니다. 장 마감 전이므로 `반등 확인` 상태라도 최종 확정 신호로 취급하지 않습니다.

## 사용자에게 직접 확인을 요구하지 않는 원칙
앱이 계산 가능한 항목은 앱이 판정합니다.

예:
- 20일선 상승 여부
- 최근 고점 이후 조정 폭
- 지지구간 접근 여부
- 지지선 저가 방어
- 가격 반등
- RSI 회복
- 거래량 회복

장중 정보가 없으면 `확인하세요`가 아니라 `현재 데이터로 미확정이며 다음 EOD에서 자동 재판정`이라고 표시합니다.

## Analysis Hub
종합 화면에는 전체 체크리스트를 펼치지 않습니다.

- 현재 정확한 단계
- 조건 확인 진행도
- 부족/실패 조건 2~3개
- 데이터 기준
- 다음 자동 확인 시점

만 요약합니다. 전체 근거는 `전략` 상세 탭 안의 `전체 자동 확인 근거`에서 필요할 때만 펼칩니다.

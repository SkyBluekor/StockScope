# StockScope v0.21.1 — Concrete Entry & Risk Guide

## 목적
Scanner와 10전략 비교 결과를 `종목 후보`에서 끝내지 않고, 기존 Strategy Engine / Risk Engine 계산을 실제 가격과 수치로 번역한다.

## 핵심 원칙
- 새로운 투자 기준값을 임의로 만들지 않는다.
- 가격 구간은 기존 전략 조건식을 그대로 역산한다.
  - `20일 고점과 x% 이내` → 해당 조건을 만족하는 실제 가격 구간
  - `지지선과 x% 이내` → 해당 조건을 만족하는 실제 가격 구간
  - `현재가 > MA20` / `MA20과 x% 이내` → 실제 MA20 가격 기준
- 거래량은 기존 `volume_ratio_20` 조건을 사용한다.
- 단순 `최근 n일 +x%` 기준이 전략에 없으면 새로 만들지 않고, 기존 MA20 slope 등 실제 조건을 보여준다.
- 손절/무효화/목표는 기존 RiskPlan의 `invalidation_price`, `target1_price`, `target2_price`를 사용한다.
- 대기 상태의 Risk 가격은 현재 확정 종가 기준 참고값이며, 조건이 바뀌면 다시 계산한다.

## 과거 검증과 현재 진입조건 분리
v0.21.1부터 과거 표본 부족만으로 현재 조건상 READY를 실패로 바꾸지 않는다.
- 현재 조건 + Risk 통과 → `현재 조건상 진입 후보`
- 과거 표본 부족 → 별도 경고
- 과거 근거 약함 → 별도 경고
- 전략 조건 부족 → WAIT
- Risk CAUTION/BLOCK → 위험 때문에 진입 보류

## 사용자 화면
Scanner 후보 카드와 10전략 결과 상단에 아래를 표시한다.
- 현재 확정 종가
- 가격 타이밍 구간/기준
- 현재가에서 해당 가격까지 필요한 변화율
- 거래량 현재 배수 / 필요한 배수
- 손절 참고가격(전략 무효가격)
- 1차 목표 / 2차 목표
- Risk:Reward
- 조건 변경 시 Risk 재계산 필요 여부

## 주의
표시 가격은 자동 주문 가격이 아니다. EOD 확정 데이터 기반 참고 기준이며 다음 확정 데이터에서 조건이 바뀌면 다시 계산한다.

## 6. Window 결정

Frozen rule:

```text

=

=
floor((n+9)/10)
```

세 horizon 모두 동일 observation-count window를 사용한다.

state t에서:

```text
W_t
=
{t-w+1,...,t}
```

future observation은 사용하지 않는다.

### 선택 이유

기존 prospective grid의 가장 이른 anchor:

```text
A02
=
ceil(2n/20)
=
ceil(n/10)
```

이다.

따라서:

```text
w(n)
=
A02 mapped N
```

가 된다.

이 window는:

1. earliest approved 10% anchor에서 정확히 full window를 갖는다.
2. earliest anchor를 보존하면서 사용할 수 있는 최대 common backward window다.
3. Development 결과, passing N, policy outcome을 전혀 보지 않고 정할 수 있다.
4. horizon마다 유리한 window를 따로 선택하지 않는다.

minimum:

```text
w >= 2
joint n >= 11
```

이다.

## 7. Empirical CDF

각 horizon h, state t:

```text
Fhat_h,t(x)
=
(1/w)
sum_{i=t-w+1}^t
I{X_i^(h) <= x}
```

T_EMP 계산 시 synthetic x-grid를 만들지 않는다.

두 window의 observed-value union에서 exact ECDF difference maximum을 계산한다.

## 8. Median

window sample을:

```text
x_(1) <= ... <= x_(w)
```

로 정렬한다.

odd w:

```text
mhat
=
x_((w+1)/2)
```

even w:

```text
mhat
=
[x_(w/2)+x_(w/2+1)]/2
```

즉 midpoint sample median이다.

ties는 그대로 유지한다.

## 9. MAD

각 window 내부에서:

```text
D_i
=
|X_i-mhat|
```

를 만든 뒤, D_i들의 midpoint sample median을:

```text
dhat
```

로 사용한다.

anchor에서:

```text

```

이면 location / scale normalization을 강제로 만들지 않는다.

```text
ANCHOR_EMPIRICAL_MAD_ZERO
```

로 fail-close한다.

## 15. Candidate status

각 anchor는:

```text
SUPPORTED_WITHIN_POLICY
EXCEEDS_POLICY
BLOCKED
```

중 하나다.

### SUPPORTED_WITHIN_POLICY

모든 horizon, 모든 later state, 모든 metric이 tolerance 이내.

### EXCEEDS_POLICY

모든 required metric이 계산 가능하지만 하나 이상 tolerance 초과.

### BLOCKED

필수 identity/window/policy/metric 계산 자체가 완료되지 못함.

## 17. Common-N

새 common-N:

```text

```

정의:

> 모든 horizon과 모든 later state에서 T_EMP/L_EMP/S_EMP가 각각 승인된 tau_T/tau_L/tau_S 이내인 가장 이른 approved anchor.

수식상:

```text
minimum N

such that

for all h in {1,5,10}
for all v=N+1,...,n

T_EMP,h(N,v) <= tau_T
L_EMP,h(N,v) <= tau_L
S_EMP,h(N,v) <= tau_S
```

의미:

> fixed observed path에서 이후 구간이 empirical drift policy 안에 머물렀던 가장 이른 approved anchor.

의미하지 않는 것:

```text
future guarantee
population-law adequacy
confidence coverage
theorem-level minimum sample size
```

# StockScope Input UX v0.15.3

## 변경 목적
v0.15.2에서 사용자의 의도를 잘못 해석해 `최근 KRX 확정 가격 바로가기` 카드가 추가되었습니다.
해당 카드는 제거하고, 기존 장중 선택 입력 자체를 모바일 친화적인 Stepper 방식으로 개선합니다.

## 현재 참고가격
- 직접 입력
- ± 1호가 버튼
- 버튼 롱프레스 연속 증감
- KRX 종가 대비 누적 ±1%, ±5%
- KRX 종가 복원
- 버튼 조정 범위 -30% ~ +30%

## 장중 추가 정보
기본 화면에서는 접힌 `장중 정보 추가 입력 (선택)` 영역으로 제공합니다.

### 오늘 고가 / 오늘 저가
- 직접 입력
- ± 1호가
- 롱프레스 연속 증감
- 빈 값에서 ± 버튼을 누르면 현재 참고가격을 기준으로 시작
- `현재 참고가격으로 설정` 버튼

### 현재 누적 거래량
- 직접 입력
- ± 버튼
- 롱프레스
- 값 규모에 따라 100 / 1,000 / 10,000 / 100,000 / 1,000,000주 단위로 자동 조절

## 분석 정책
장중 고가/저가/누적 거래량은 선택값입니다.
입력하지 않아도 분석은 정상 실행하며 KRX 확정 EOD 기반 ATR/거래량 지표를 사용합니다.

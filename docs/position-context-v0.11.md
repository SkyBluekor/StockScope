# Position Context + Automated Strategy Checks v0.11

## 목적

기존 전략 가이드에서 프로그램이 계산 가능한 항목까지 사용자에게 "확인하세요"라고 요구하던 문제를 수정합니다.

## Position Context

- NOT_HELD: 신규 진입 관점
- HOLDING: 사용자가 입력한 평균 매수가/수량을 기준으로 보유 포지션 관점

입력값은 실제 증권계좌와 연결되지 않으며 분석 요청에서만 사용합니다.

## 보유 중 자동 계산

- 평균 매수가 대비 수익률
- 수량 입력 시 평가손익
- 현재 분석가격의 20일선 상/하 위치
- 기존 지지 후보 유지 여부
- 최근 저점 구조
- Risk Engine 전략 무효화 기준 유지 여부

## 전략별 프로그램 자동 점검

각 전략 카드에서 PASS / WARN / FAIL / UNKNOWN으로 직접 표시합니다.

예:

- 20일선 위치
- 20일선 기울기
- 최근 저점 구조
- 지지 가격 거리
- 저항 가격 거리
- 거래량 조건
- RSI 조건
- 돌파 전략의 20일 고점 접근 여부
- 박스권 전략의 시장 국면

`앞으로 관찰할 항목`은 자동 점검 결과가 이후 바뀌는지 추적하는 용도로만 사용합니다.

# StockScope Event Impact Engine v0.13

## 목적

OpenDART 공시를 단순 위험 목록으로 보여주는 대신 다음 순서로 해석합니다.

1. 공시 유형/방향 분류
2. 구조화 OpenDART API 또는 공시 원문에서 핵심 조건 추출
3. 최근 연매출 등 회사 규모와 비교
4. KRX 확정 데이터 또는 사용자가 입력한 현재 참고가격으로 공시 전후 가격 반응 확인
5. 전략별 강화/약화 방향 설명
6. 미보유/보유 상태에 맞춘 조건부 대응 가이드 생성

## 출력

- 방향: POSITIVE / NEGATIVE / MIXED
- 영향도: HIGH / MEDIUM / LOW
- 분석 신뢰도: HIGH / MEDIUM / LOW
- 핵심 조건
- 가격/거래량 반응
- 전략별 영향
- 사용자 대응
- 후속 관찰 항목

## 회사 규모 비교

판매·공급계약은 가능하면 OpenDART `fnlttSinglAcntAll.json`의 최근 사업보고서 매출액과 비교합니다.

예시:

- 계약금액 200억원
- 최근 연매출 1,000억원
- 최근 연매출 대비 20%

매출계정이나 계약금액을 안정적으로 추출하지 못하면 비율을 임의로 만들지 않고 `데이터 부족`으로 둡니다.

## 가격 반응

공시 접수일 이전 마지막 KRX 확정 종가를 기준점으로 사용합니다.

- 사용자가 현재 참고가격을 입력한 경우: USER_REFERENCE
- 입력하지 않은 경우: 최근 KRX 확정 종가

사용자 현재 참고가격은 KRX 원본 시계열에 저장하거나 덮어쓰지 않습니다.

## Risk Gate

`HIGH`라는 이유만으로 모두 신규진입을 차단하지 않습니다.

현재 v0.13은 **NEGATIVE + HIGH** 이벤트만 하드 Risk Gate 후보로 사용합니다.
긍정 계약처럼 영향도가 크더라도 방향이 긍정이면 가격 반영 정도와 전략 조건을 별도로 평가합니다.

## 한계

- OpenDART 원문은 비정형 문서가 있어 모든 수치를 자동 추출할 수 없습니다.
- 공시 해석은 원문을 대체하지 않습니다.
- 가격 반응은 KRX EOD 또는 사용자가 입력한 참고가격 기반이며 실시간 증권사 시세가 아닙니다.
- Event Impact는 실제 매수/매도 주문을 실행하지 않습니다.

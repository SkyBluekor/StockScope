# StockScope Input UX v0.15

## 목적

모바일과 PC에서 현재 참고가격, 평균 매수가, 보유 수량을 매번 키보드로 입력해야 하는 불편을 줄입니다. 직접 입력은 유지하면서 버튼 조작을 추가합니다.

## 현재 참고가격

- 숫자 직접 입력
- 천 단위 콤마 자동 표시
- `- / +` 버튼으로 KRX 호가가격단위만큼 이동
- `-5% / -1% / KRX 종가 / +1% / +5%` 빠른 이동
- 퍼센트 버튼은 KRX 최근 확정 종가를 기준으로 계산
- 계산된 가격은 해당 가격대의 호가가격단위에 맞춰 반올림

KRX 호가가격단위는 다음 구간을 사용합니다.

| 가격 | 단위 |
| --- | ---: |
| 2,000원 미만 | 1원 |
| 2,000원 이상 ~ 5,000원 미만 | 5원 |
| 5,000원 이상 ~ 20,000원 미만 | 10원 |
| 20,000원 이상 ~ 50,000원 미만 | 50원 |
| 50,000원 이상 ~ 200,000원 미만 | 100원 |
| 200,000원 이상 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

## 평균 매수가 / 수량

- 평균 매수가: 직접 입력 + 가격 단위 `- / +`
- 입력이 비어 있을 때 처음 `- / +`를 누르면 최근 KRX 종가를 시작값으로 사용
- 보유 수량: 직접 입력 + 1주 단위 `- / +`
- 실제 계좌 연결이나 주문 기능은 없음

## 분석 결과 최신성

분석 완료 후 다음 값 중 하나라도 바뀌면 결과를 자동으로 최신 결과처럼 취급하지 않습니다.

- 현재 참고가격
- 오늘 고가 / 저가 / 거래량
- 보유 여부
- 평균 매수가
- 보유 수량

기존 결과는 화면에 유지하지만 `입력값이 변경되었습니다` 경고와 `변경값 다시 분석` 버튼을 표시합니다.

## Windows timezone 보완

`ZoneInfo("Asia/Seoul")`을 Windows에서도 안정적으로 사용할 수 있도록 `tzdata`를 백엔드 필수 의존성으로 추가했습니다. 새 clone에서는 `setup.ps1`이 자동 설치합니다.

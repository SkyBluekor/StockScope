# StockScope v0.21.0.1 — Scanner Fast Start & Progress

## 목적
Scanner 첫 실행에서 장기 과거 데이터를 수백 회 자동 동기화하느라 몇 분씩 기다리는 문제와, 0%/50%에서 멈춘 것처럼 보이는 진행 UI를 함께 개선한다.

## 핵심 변경
- Scanner 자동 데이터 준비 범위를 현재 전략 계산에 필요한 최근 구간으로 축소.
- `KRX_SCANNER_FAST_REQUEST_LIMIT` 기본값 60회. 예상 신규 네트워크 요청이 이를 넘으면 대량 동기화를 자동 시작하지 않는다.
- 저장된 데이터로 가능한 범위에서 먼저 Scanner를 실행한다.
- 장기 과거 근거가 로컬에 있으면 재사용하고, 없으면 `과거 검증 전` 후보로 명확히 표시한다.
- 장기 과거 데이터가 없다는 이유로 Scanner 결과 전체를 막지 않는다.
- 진행률을 데이터 확인 → 최근 시장 데이터 → 빠른 검사 → 상위 후보 분석 → 결과 정리 단계로 분리한다.
- 현재 처리 종목, 처리 개수, 경과시간, 마지막 진행, 예상/실제 KRX 요청을 표시한다.
- 30초 무진행 시 지연 안내, 90초 무진행 시 강한 경고를 표시한다.
- 기존 작업 취소 기능을 유지하며 이미 Market Store에 저장된 데이터는 보존한다.
- Scanner 결과 캐시는 완전한 데이터로 계산된 결과에만 저장한다. 부분 데이터 결과는 당일 고정하지 않는다.

## 대량 데이터 준비
자동 한도를 넘는 경우 결과 화면에 `시장 데이터 준비 시작`을 제공한다. 사용자가 명시적으로 누른 경우에만 60회 이상의 최근 시장 데이터 준비를 허용한다. KRX 일일 8,000회 안전 Budget은 그대로 적용된다.

## 과거 검증 수준
- `CURRENT_AND_HISTORY`: 현재 조건 + 로컬에 이미 존재하는 과거 근거까지 검증.
- `CURRENT_ONLY`: 현재 조건으로 후보를 추렸지만 장기 과거 검증은 아직 수행하지 않음.

과거 검증 전 후보는 매수 추천이 아니며 화면에서 검증 수준을 분명하게 표시한다.

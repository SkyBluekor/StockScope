# StockScope Position Action Guide v0.11.1

## 목적
보유 포지션 자동 점검을 단순 지표 나열로 끝내지 않고,
사용자가 다음 대응 방향을 이해할 수 있도록 조건부 행동 가이드로 변환합니다.

## 출력 범주
- 보유 관찰
- 추가매수 보류
- 조건부 추가매수 검토
- 리스크 축소 검토
- 전략 종료·정리 검토

## 원칙
- 손실 중이라는 이유만으로 물타기를 권하지 않습니다.
- 수익 중이라는 이유만으로 무조건 보유를 유지하지 않습니다.
- 추가매수는 Risk Gate 비활성, 전략 적합도, 지지/MA20 근접, R:R 등 복수 조건이 동시에 충족되어야 '조건부 검토'로 표시합니다.
- 전략 무효화 기준이 깨지면 기존 진입 논리를 유지하지 않고 재평가를 우선합니다.
- 모든 출력은 의사결정 보조이며 실제 증권사 주문을 실행하거나 전송하지 않습니다.

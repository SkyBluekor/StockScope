# StockScope v0.19.7 — Backtest Action UX

## 목적

백테스트 결과를 통계 보고서가 아니라 사용자가 바로 이해하고 다음 행동으로 이어갈 수 있는 화면으로 재구성한다.

기본 결과 화면은 다음 네 질문에 먼저 답한다.

1. 현재 이 전략을 어떻게 봐야 하는가?
2. 가장 먼저 해결할 문제는 무엇인가?
3. 어떤 해결 방향이 유력한가?
4. 지금 가장 먼저 무엇을 해야 하는가?

## 변경 사항

### 1. 결과 첫 화면 압축

기존의 분석 카드와 상세 표를 먼저 노출하지 않고 다음 순서만 기본 노출한다.

- 현재 판단
- 가장 먼저 해결할 문제
- 추천 해결 방향
- 지금 가장 먼저 할 일

Risk Policy 교차검증이 필요한 경우 대표 종목 자동 검증을 기본 행동으로 제시한다. 교차검증 완료 후에는 해당 결과를 같은 상단 영역에서 즉시 반영한다.

### 2. 상세 자료 기본 접힘

다음 영역은 기본적으로 닫힌 상태로 시작한다.

- 계산 정확성 점검
- Risk 정책 비교 근거
- 문제 해결 판단 상세
- 전체 숫자
- 진입 시점 비교
- 시장 상황별 결과
- 전략 적합도 검증
- 실제 문제 거래
- 실행 성능
- 방법론과 한계

### 3. 접기/펼치기 상태 명시

모든 접이식 영역은 상태에 따라 다음과 같이 표시한다.

- 닫힘: `펼치기 ▼`
- 열림: `숨기기 ▲`

설정 화면의 계산 기준도 `기준 보기 ▼ / 기준 숨기기 ▲`로 동일한 원칙을 적용한다.

개별 거래 계산 경로는 다음과 같이 표시한다.

- 닫힘: `왜 이렇게 계산됐는지 보기 ▼`
- 열림: `계산 근거 숨기기 ▲`

### 4. 상세 영역도 의미를 먼저 설명

진입 시점, 시장환경, 전략 적합도 상세를 열었을 때 표부터 보여주지 않고 현재 표본에서 상대적으로 나았던 구간과 해석 주의사항을 먼저 표시한다.

### 5. 실제 거래 압축

전체 거래 수와 주의 거래 수를 먼저 요약하고, 감사 결과에서 가장 먼저 확인할 거래가 있으면 해당 거래를 우선 표시한다.

## 변경하지 않은 것

- 백테스트 계산 공식
- Risk Engine 규칙
- CAUTION 차단 정책
- 12% 손절 제한의 실제 적용
- 진입 3/7~7/7 계산
- KRX 데이터 수집 및 캐시 구조

이번 버전은 기존 v0.19.6 분석 결과를 사용자 행동으로 연결하는 프론트 UX 변경이다.

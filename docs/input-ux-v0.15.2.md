# StockScope Input UX v0.15.2

## 목적

현재 참고가격을 모바일에서도 거의 키보드 없이 맞출 수 있도록 v0.15 입력 방식을 보완합니다.

## 현재 참고가격 조작

### 1. 직접 입력

- 숫자를 직접 입력할 수 있습니다.
- 입력값은 천 단위 콤마로 표시됩니다.
- 직접 입력은 버튼 조작과 함께 사용할 수 있습니다.

### 2. `- / +` 호가 버튼

- 짧게 누르면 현재 가격대의 KRX 호가가격단위만큼 한 단계 이동합니다.
- 약 0.32초 이상 꾹 누르면 자동 반복이 시작됩니다.
- 오래 누를수록 반복 간격을 줄여 빠르게 이동합니다.
- 손을 떼거나 포인터 입력이 취소되면 즉시 멈춥니다.
- 마우스, 터치, 펜 입력을 공통 Pointer Event로 처리합니다.
- 현재 참고가격에서 최근 확정 종가를 기준으로 사용하는 버튼 조정은 `-30% ~ +30%` 범위를 넘지 않습니다.

### 3. 누적 퍼센트 버튼

`-5% / -1% / KRX 종가 / +1% / +5%`를 제공합니다.

퍼센트 버튼은 매번 동일한 고정 가격으로 이동하지 않습니다.

예:

```text
KRX 종가 대비 0%
+5% → +5%
+5% → +10%
+5% → +15%
-1% → +14%
```

최대 버튼 조정 범위는 `-30% ~ +30%`입니다. 실제 표시 가격은 해당 가격대의 호가단위에 맞추기 때문에 표시 변동률에는 소수점 수준의 차이가 날 수 있습니다.

`KRX 종가` 버튼은 누적 변동률을 0%로 되돌립니다.

## 최근 확정 OHLC 빠른 선택

종목 조회 결과의 최근 KRX 확정 일봉에서 다음 가격을 바로 선택할 수 있습니다.

- 시가
- 고가
- 저가
- 종가

각 버튼에는 실제 가격과 확정 데이터 날짜를 표시합니다.

이 값들은 **최근 확정 일봉**입니다. 사용자가 알고 있는 오늘 장중 고가·저가와 동일하다고 가정하지 않으며, 오늘 장중 고가·저가는 기존 선택 입력란에서 별도로 넣습니다.

## 평균 매수가 / 보유 수량

- 평균 매수가는 직접 입력과 `- / +` 가격 조절을 함께 사용합니다.
- 보유 수량은 직접 입력과 1주 단위 `- / +`를 사용합니다.
- 실제 증권계좌와 연결하거나 주문을 실행하지 않습니다.

## 분석 최신성

가격, 평균 매수가, 수량 등 분석 입력이 바뀌면 기존 분석 결과를 최신 결과처럼 표시하지 않습니다.

`입력값이 변경되었습니다` 상태와 `변경값 다시 분석` 버튼으로 재분석을 유도합니다.

# StockScope Analysis Hub v0.16.5

## 목적
분석 엔진이 늘어날수록 모든 결과를 한 페이지에 펼쳐 놓으면 사용자는 긴 보고서를 읽어야 합니다.
v0.16.5는 `결론 → 필요한 상세 영역 선택 → 근거 확인` 순서로 UX를 바꿉니다.

## 첫 화면
전략 분석 완료 직후에는 상세 패널을 전부 펼치지 않습니다.

먼저 다음만 보여줍니다.
- 종합 판단
- 사용자의 현재 관점(미보유/보유)
- 가장 중요한 대응 방향
- 우선 전략
- 전략 / 눌림·지지 / 시장 상대강도 / 업종 상대강도 / 공시 / 리스크 신호
- 핵심 근거
- 판단이 바뀌는 조건

## Navigation
상세 화면은 한 번에 하나만 표시합니다.
- 종합
- 전략
- 위험
- 상대강도
- 공시
- 지표

분석을 다시 실행하면 기본 화면은 항상 `종합`으로 돌아옵니다.

## 원칙
1. 사용자는 모든 분석 패널을 읽지 않아도 현재 결론을 이해할 수 있어야 합니다.
2. 원시 데이터와 계산 근거는 필요할 때만 확인합니다.
3. 서로 다른 엔진의 신호가 충돌하면 종합 요약에서 충돌 사실을 보여줍니다.
4. Risk Gate가 활성화되면 긍정 신호보다 위험 조건을 우선합니다.
5. 종합 판단은 실제 매수/매도 주문 지시가 아닙니다.

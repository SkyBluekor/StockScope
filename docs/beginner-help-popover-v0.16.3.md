
# Beginner Help Popover v0.16.3

## UX 규칙
도움말 `?`은 장시간 고정되는 패널이 아니라 임시 팝오버입니다.

동작:
- `?` 클릭 → 열기
- 같은 `?` 다시 클릭 → 닫기
- 팝오버 바깥 클릭/탭 → 닫기
- ESC → 닫기 및 트리거로 포커스 복귀
- 다른 `?` 클릭 → 기존 도움말 자동 닫기
- 우측/하단 화면 경계에 가까우면 팝오버 위치 자동 보정
- 모바일에서도 동일한 동작 + 명시적 × 닫기 버튼

## 목적
도움말이 본문을 가린 채 남아 있지 않도록 하고,
여러 도움말이 동시에 떠 화면이 복잡해지는 문제를 방지합니다.

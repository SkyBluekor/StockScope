# Investor Style UX Compression v0.18.2.1

## 목적
v0.18.2의 Entry Timing 계산과 백엔드 계약은 변경하지 않고, 투자스타일 화면에서 반복되던 정보를 압축한다.

## 변경
- 네 투자방식 설명은 기본 접힘으로 이동.
- 종목 적합도 순위와 관점 선택을 한 줄의 compact ranking UI로 통합.
- 첫 화면 핵심을 `현재 행동 / 기업 조건 / 단기 타이밍 / 가장 부족한 조건`으로 재구성.
- `앱이 이미 분석한 결과`, `현재 행동과 판단 변경 조건`, `왜 이렇게 판단했나`를 기본 접힘으로 이동.
- 제한 요소가 없을 때 큰 빈 카드 대신 `큰 제한 요소 없음` badge만 표시.
- 장기 스타일 적합성 ≠ 현재 단기 행동이라는 중복 카드는 제거하고 핵심 요약 구조 자체에서 두 판단을 분리.
- 해석 원칙은 도움말 성격이므로 기본 접힘 처리.

## 비변경 범위
- Entry Timing 계산 규칙
- Investor Style 점수 계산
- Strategy/Risk/Fundamental 엔진
- API 응답 계약

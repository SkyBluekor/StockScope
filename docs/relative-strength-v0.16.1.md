
# Relative Strength v0.16.1 — Result First

## 문제
v0.16은 5/20/60거래일 상대수익률을 정확히 계산했지만,
사용자가 숫자를 보고 직접 결론을 내려야 했습니다.

## 변경
메인 화면은 데이터가 아니라 프로그램 해석을 우선합니다.

분류 예:
- 시장 주도형
- 단기 회복형 강세
- 강하지만 둔화
- 완만한 시장 우위
- 시장과 비슷
- 약세 회복 시도
- 시장 소외형

각 결과는 다음을 제공합니다.
1. 현재 결론
2. 미보유/보유 상황별 대응 방향
3. 우선 검토할 전략
4. 우선순위를 낮출 전략
5. 판단 근거
6. 판단이 바뀌는 조건

5/20/60일 원시 상대수익률은 `근거 데이터 보기` 안으로 이동합니다.

## 원칙
상대강도 결과는 하나의 분석 축이며 실제 매수·매도 주문 명령이 아닙니다.
현재 참고가격은 실시간 시장지수와 시점이 맞지 않으므로 상대강도에는 섞지 않습니다.

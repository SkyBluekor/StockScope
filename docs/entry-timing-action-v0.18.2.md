# StockScope v0.18.2 — Entry Timing Action Engine

## 목표

`반등 확인 대기`처럼 결과만 보여주던 단기 진입 카드를 다음 구조로 바꾼다.

1. 현재 행동
2. 앱 자동 확인 진행도
3. 확인된 조건 / 아직 부족한 조건
4. 계산 가능한 가격 기준
5. 판단 규칙
6. 다음 데이터에서 자동 재판정

조건 확인 개수는 상승확률이나 매매 성공확률이 아니다.

## 자동 확인 7개 조건

Pullback 계열은 기존 `PullbackConfirmationAnalyzer`를 확장해 다음 조건을 같은 엔진에서 판정한다.

- 기존 상승 추세
- 최근 고점에서 조정
- 지지구간 접근
- 실제 지지 유지
- 가격 반등 신호
- RSI 반등
- 반등 거래량

새 엔진을 중복 생성하지 않고 기존 `auto_check` 결과를 `entry_timing` 계약으로 확장한다.

## v0.18.2 판정 보강

### 가격 반등

KRX 확정 EOD:
- 종가가 시가보다 높음
- 종가가 계산된 지지 anchor 아래가 아님
- 반등 확인 후보 가격은 `max(시가, 지지 anchor)`처럼 실제 관측/계산 값만 사용

장중 Preview:
- 사용자가 오늘 저가를 제공한 경우
- 저가가 지지구간을 시험하고
- 현재가가 지지 anchor 위로 회복했는지 자동 판정

임의의 `+1% 목표가` 같은 근거 없는 확인 가격은 만들지 않는다.

### RSI 회복

- 현재 RSI가 40 이상
- 비교 기준 RSI보다 1p 이상 회복
- EOD는 직전 거래일 RSI와 비교
- 장중 Preview는 최신 확정 EOD RSI와 예상 현재 RSI를 비교

### 거래량 회복

- 현재 거래량비가 최근 20일 평균의 1.0배 이상이면 PASS
- 데이터가 없으면 추측하지 않고 UNKNOWN

## 행동 분리

미보유 대기 상태:
- 현재 행동: `신규 추격 대기`
- 다음 단계: `반등 확인 시 후보 검토`
- 피할 행동: `반등 확인 전 추격 진입`

보유 대기 상태:
- 현재 행동: `보유 관찰`
- 다음 단계: `반등 확인 시 보유 근거 개선 여부 검토`
- 피할 행동: `반등 미확인 상태의 추가매수`

## 가격 기준

`analysis_summary.entry_timing.levels`에서 다음 값을 제공한다.

- 현재가
- MA20
- 주요 지지
- 선택된 지지 anchor
- 반등 확인 후보
- Risk Engine 전략 무효화 가격

값을 계산할 수 없으면 `null`로 두고 UI에서 숨긴다.

## Investor Style 통합

단기 타이밍의 중요도를 스타일별로 다르게 처리한다.

- Buffett: 보조 — 기업 품질/가격 매력이 중심
- Graham: 보조 — 안전마진/재무 안정성이 중심
- Lynch: 중요 — 성장/가격이 좋아도 단기 타이밍 미완료 시 신규 추격 대기
- CAN SLIM: 매우 중요 — Pullback 상태를 재사용하지 않고 C/S/L/M 자체 핵심 타이밍을 사용

CAN SLIM 핵심 타이밍:
- C: 최근 실적 성장
- S: 거래량·수요
- L: 시장 주도력
- M: 시장 환경

## Analysis Hub 안전장치

Pullback / Support Bounce / MA20 Rebound / Trend Recovery처럼 눌림·지지 판정과 직접 연결되는 전략에서만 `entry_timing.relevant=true`로 표시한다.

Breakout 등 다른 전략이 상위 전략일 때는 Pullback 실패를 전체 행동 게이트로 사용하지 않는다. Pullback 신호는 참고용 NEUTRAL 신호로 남긴다.

## UI

Analysis Hub 첫 화면은 중복 카드를 늘리지 않고 다음 정보를 한 영역에 압축한다.

- 기업 조건
- 전략 형태 적합도
- 단기 진입 타이밍(관련 전략일 때만)
- 자동 확인 진행도
- 가장 부족한 조건
- `진입 타이밍 상세` 버튼

상세 화면에서만 확인/부족 조건, 가격 기준, 판정 규칙, 전체 7개 조건을 펼친다.

## 검증

Overlay 작업 환경에서 다음을 포함한 관련 회귀 테스트 20개를 통과했다.

- EOD 반등 가격 계산
- 장중 저가 기반 가격 회복
- 장중 RSI vs 최신 확정 RSI 비교
- 보유/미보유 행동 분리
- Risk 무효화 가격 연결
- Investor Style 연동
- Buffett/Graham 단기 타이밍 보조 처리
- CAN SLIM 자체 C/S/L/M 타이밍
- 비-Pullback 상위 전략이 Pullback 실패로 차단되지 않는지 검증
- TypeScript strict type-check

전체 로컬 프로젝트 적용 후에는 기존 전체 백엔드 테스트도 다시 실행한다.

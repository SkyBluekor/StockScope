# StockScope v0.9.1 — EOD 기준과 현재 참고 시나리오 분리

## 수정 이유
v0.9는 현재 참고가격으로 일부 지표를 재계산했지만 화면에서 확정 EOD 전략과 현재 참고 시나리오의 차이가 명확하지 않았습니다.

## v0.9.1 원칙
- KRX 확정 일봉은 불변입니다.
- EOD 전략과 현재 참고가격 전략을 **각각 별도로 계산**합니다.
- 화면에서 전략별 `EOD 점수 → 현재 시나리오 점수` 변화를 보여줍니다.
- 현재가격만 입력하면 예상 MA20/RSI 및 가격 위치를 갱신합니다.
- 오늘 고가/저가/누적 거래량은 선택 입력이며, 제공되면 예상 ATR/거래량 조건까지 보완합니다.
- 현재 입력이 부족한 전략은 `부분 반영`으로 표시합니다. 특히 돌파/모멘텀/변동성 전략은 당일 거래량 확인이 중요합니다.
- 사용자 입력값은 KRX 캐시나 확정 히스토리에 저장하지 않습니다.
- 실제 주문 기능은 구현하지 않습니다.

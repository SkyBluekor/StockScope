# StockScope v0.9 — 현재 참고가격 Override 설계

## 목적
KRX Open API의 최근 확정 일봉(EOD)은 그대로 보존하면서, 사용자가 다른 증권 앱에서 확인한 현재 가격을 **임시 참고값**으로 입력해 장중 상황과의 괴리를 보완합니다.

## 절대 원칙
- 사용자 입력 가격은 KRX 원본 일봉/캐시/DB에 쓰지 않습니다.
- 실제 매수·매도 주문은 수행하지 않습니다.
- 현재가 하나만으로 갱신할 수 없는 ATR/거래량은 최근 확정 EOD 값을 유지합니다.

## 임시 재계산 가능
- 확정 종가 대비 현재 참고가격 변화율
- 현재가격을 임시 종가로 가정한 예상 MA20
- 현재가격을 임시 종가로 가정한 예상 RSI14
- 기존 지지/저항 후보까지의 현재 거리
- 기존 20일 고점과의 현재 거리

## Data Freshness
- `CONFIRMED_EOD`: KRX 최근 확정 데이터만 사용
- `REFERENCE_UPDATED`: 사용자 현재가 반영, 괴리 정상 범위
- `STALE`: 확정 종가와 현재 참고가격의 차이가 커 기존 분석 신선도 저하
- `EXTREME_MOVE`: ATR 기반 동적 임계치보다 큰 급등/급락. Risk Gate 우선

임계치는 v0.9 초기값으로:
- STALE = `max(5%, ATR% × 1.5)`
- EXTREME_MOVE = `max(8%, ATR% × 2.0)`

향후 백테스트/실데이터 검증 후 조정합니다.

## NO TRADE 표현
`NO TRADE`는 전략 점수가 아닙니다. 따라서 100점 같은 점수를 제거하고 `매매 보류 / Risk Gate` 상태로 표시합니다. Risk Gate가 활성화되어도 다른 전략의 적합도는 참고용으로 계속 보여줍니다.

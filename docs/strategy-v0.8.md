## 종목 검색 UX
- 종목코드 직접 입력을 기본 UX에서 제거
- KRX 유가증권/코스닥 종목기본정보를 이용해 종목명 또는 6자리 코드 검색
- 검색 결과 선택 시 시장과 종목코드를 자동 설정
- KRX 종목기본정보는 날짜별 캐시 재사용
